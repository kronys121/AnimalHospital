# Мастер-роадмап: "Animal Hospital" — от каркаса до полной игры

Один документ, по которому можно идти от начала до конца. Логика: сперва собираем всю больницу целиком (визуально готово, но большинство комнат — заглушки), делаем полностью рабочим только один цикл, затем поочерёдно "включаем" остальные комнаты и механики маленькими шагами. Каждый этап — самостоятельно играбельный, не ломает предыдущие.

Отдавай Claude Code по одному этапу за раз, не всё сразу. После каждого этапа — проверяй в Studio, что смена проходится от начала до конца, и только потом переходи дальше.

---

## Этап 0. Каркас больницы (сцена, без скриптов)

Собрать в Roblox Studio:

- **Ресепшн** — окно приёма, точка спавна пациента.
- **Коридор** — соединяет ресепшн со всеми кабинетами.
- **Basic Medical / DNA (Room 1)** — станет рабочей комнатой первой.
- **X-Ray (Room 2)** — заглушка.
- **Heart Monitor (Room 7)** — заглушка.
- **Surgery (Room 8)** — заглушка.
- **Комната отдыха / будущий магазин** — точка-заглушка.

Каждая комната — отдельная модель-папка в Workspace с единой структурой: `EntryPoint`, `InteractionZone`, `RoomLabel` (табличка с названием, чтобы не путаться, пока UI не готов).

## Этап 1. Архитектура комнат (`RoomRegistry`)

ModuleScript с таблицей всех комнат:
```
Rooms.BasicMedical = { name = "Basic Medical", isImplemented = true,  onPatientEnter = function(patient) ... end }
Rooms.XRay         = { name = "X-Ray",         isImplemented = false, onPatientEnter = function(patient) ... end }
Rooms.HeartMonitor = { name = "Heart Monitor", isImplemented = false, onPatientEnter = function(patient) ... end }
Rooms.Surgery      = { name = "Surgery",       isImplemented = false, onPatientEnter = function(patient) ... end }
```
Если `isImplemented = false` — заглушка сама "лечит" пациента случайным исходом через 5 секунд, чтобы цикл не зависал. Это позволяет позже подменять `onPatientEnter` на реальную мини-игру в любой комнате, не трогая остальной код.

## Этап 2. Пациент и данные (`PatientData`)

ModuleScript-генератор пациента:
```
{
    name = "Хомяк Джерри",
    isAnomaly = false,
    visualTraits = {},              -- признаки аномалии, если isAnomaly = true
    correctMedicine = "MedicineA",
}
```
Стартовые признаки аномалии (позже расширим):
- `tooManyTeeth`
- `twitching`
- `wrongVoice`

`GeneratePatient()` — рандомно решает, аномалия или нет (например, 1 из 4), при аномалии выбирает 1-2 признака.

## Этап 3. Ресепшн и осмотр

- UI-карточка при взаимодействии с пациентом: имя, "осмотреть внимательно", "впустить", "отклонить".
- Решение валидируется на сервере:
  - Обычный + впущен → уходит в случайную комнату через `RoomRegistry`.
  - Обычный + отклонён → штраф Sanity.
  - Аномалия + впущена → урон Sanity + скример-заглушка.
  - Аномалия + отклонена → +Sanity, +очки.

## Этап 4. Sanity и таймер смены

- Sanity 0-100, полоска в UI.
- +5 верное решение, -15 неверное, -1/сек простой на ресепшене.
- Таймер смены — 5 минут.
- Конец: победа (таймер истёк) или поражение (Sanity ≤ 0), экран результатов, кнопка "заново".

## Этап 5. Basic Medical — первая полностью рабочая комната

- 3 кнопки-препарата, таймер выбора 15 сек.
- Верно → пациент вылечен, +очки, +Sanity.
- Неверно/просрочено → пациент умирает, -Sanity.
- Это эталонный паттерн (таймер + выбор + исход), который дальше копируется в другие комнаты.

## Этап 6. Скример-заглушка

- Чёрная вспышка + звук + тряска камеры при впуске аномалии. Без реальной модели монстра — это добавим позже.

**После этапов 0-6 игра уже полностью проходима от начала до конца смены**, вся больница на месте визуально, работает один кабинет, остальные — честные заглушки со случайным исходом.

---

## Этап 7. Углубить осмотр аномалий

- Признак виден только если игрок реально навёл камеру/курсор на нужную часть модели (например, пасть для `tooManyTeeth`).
- `twitching` проявляется только при наблюдении от 3 секунд.
- Добавить 2-3 новых признака аномалии.
- Плейтест 5 смен подряд — проверить, не слишком ли легко/сложно угадывать.

## Этап 8. Включить X-Ray

- Заменить заглушку в `RoomRegistry` на реальную мини-игру: навести аппарат на случайную "проблемную зону", сделать снимок, выбрать один из 3 диагнозов.
- Проверить, что оба рабочих кабинета (Basic Medical + X-Ray) не конфликтуют при параллельной обработке двух пациентов.

## Этап 9. Простой враг-окружение (Don't Look Up)

- Спавн на потолке кабинета, 20% шанс раз в минуту.
- Если игрок смотрит вверх дольше 1 сек — урон Sanity.
- Исчезает сам через 15-20 сек, без преследования.

## Этап 10. Магазин (включить комнату-заглушку)

- Экран между сменами: заработанные Animal Coins.
- Кофе (+20 Sanity разово), еда (+15 Sanity разово) — для старта хватит двух предметов.
- Инвентарь на 2 слота, использование — кнопкой в UI во время смены.
- Валюта сохраняется через DataStore (аккуратно с race conditions при выходе игрока).

## Этап 11. Включить Heart Monitor + второй враг (Wall Anomaly) + настоящий скример

- Heart Monitor: кликер (белые иконки — клик, черепа — избегать), прогресс до 100%, финальный выбор препарата с повышенной ценой ошибки.
- Wall Anomaly: спавн на стене коридора, преследует при приближении, урон Sanity при контакте, отпугивается бездействием игрока.
- Заменить скример-заглушку на реальную модель монстра вблизи камеры.

## Этап 12. Включить Surgery + враг внутри мини-игры

- Самая сложная мини-игра из четырёх комнат.
- Surgery Tentacles — спавнится во время операции, отпугивается конкретным действием/предметом, совмещается с прогрессом хирургии.

## Этап 13. Первый постоянный NPC

- Один NPC с 2-3 репликами, появляется в фиксированный момент смены, даёт подсказку/мини-квест.
- Диалоги — ModuleScript-таблица, чтобы легко добавлять новых NPC позже.
- Пока без угрозы от NPC — только полезная роль.

## Этап 14. Прогрессия смен

- Все параметры сложности (частота аномалий/врагов, длина таймеров) — в конфиг-таблицу по номеру смены.
- Линейный рост сложности со смены 1 по 5.
- Плейтест каждой смены отдельно — не должно быть нечестного нагромождения угроз.

## Этап 15. Первый релизный срез (v1.0)

- Довести UI меню/смены/результатов до законченного вида.
- Звук: фоновый эмбиент + звуки на каждое действие.
- Багфиксинг, плейтест (можно соло — кооп не обязателен для v1.0).
- Публикация закрытого теста в Roblox (Private/Unlisted), сбор фидбека.

## После v1.0 — уже не маленькие шаги, а крупные блоки

- Кооператив на нескольких игроков одновременно.
- Классы персонажей (Doctor, Secretary, Psychologist) с пассивками на Sanity.
- CCTV-камеры как отдельный способ обнаружения аномалий.

- Эндлесс-режим и лидерборды.
- Полноценный сюжет на 5 историй-смен, "тёмная" сторона NPC-персонажей.

---

## Как работать с Claude Code по этому документу

1. Кидать за раз только один этап (например "Этап 3") — не блок целиком.
2. После каждого этапа — самому проверить в Studio, что смена проходится от начала до конца, прежде чем двигаться дальше.
3. Раз в 2-3 этапа — просить кратко пересказать текущее содержимое `RoomRegistry` и общую архитектуру, чтобы не терять картину проекта.
4. Порядок этапов 8, 10, 11, 12 (включение комнат/магазина) можно менять местами — они изолированы через `RoomRegistry` и не зависят друг от друга.
