# Этап 0. Планировка больницы

Справочник по геометрии, которую строит `src/server/BuildHospital.server.lua`.
Все координаты в студах, пол каждой комнаты лежит верхней гранью на `Y = 0`.

## Общие размеры

| Параметр | Значение |
| --- | --- |
| Высота стен | 14 |
| Толщина стен | 1 |
| Высота дверного проёма | 9 |
| Толщина пола и потолка | 1 |
| Ширина коридора | 12 (Z от -6 до 6) |
| Длина коридора | 80 (X от -10 до 70) |

## Комнаты

Каждая комната может иметь несколько дверей (`doors` в коде). `owns = true`
значит комната строит эту стену сама (с проёмом), `owns = false` — стену
с проёмом строит сосед (коридор или соседняя комната), и эта комната ту
стену вообще не трогает, чтобы не было двух частей в одной плоскости.

| Комната | Центр (X, Z) | Размер (X x Z) | Двери |
| --- | --- | --- | --- |
| Lobby (вход) | (-53, 0) | 22 x 26 | западная X = -64, ширина 8, строит сама (уличный вход); восточная X = -42, ширина 10, строит Reception |
| Reception | (-26, 0) | 32 x 26 | западная X = -42, ширина 10, строит сама (в Lobby); восточная X = -10, ширина 12, строит сама (в коридор) |
| BasicMedical (Room 1) | (8, -16) | 24 x 20 | южная, Z = -6, ширина 10, строит коридор |
| XRay (Room 2) | (8, 16) | 24 x 20 | северная, Z = 6, ширина 10, строит коридор |
| HeartMonitor (Room 7) | (44, -16) | 24 x 20 | южная, Z = -6, ширина 10, строит коридор |
| Surgery (Room 8) | (44, 16) | 24 x 20 | северная, Z = 6, ширина 10, строит коридор |
| BreakRoom (магазин) | (82, 0) | 24 x 24 | западная, X = 70, ширина 12, строит сама |

Lobby и Reception одинаковой высоты по Z (26, от -13 до 13), поэтому общая
стена между ними построена целиком одной из комнат без разрывов по краям.

## Маршрут пациента

`Lobby.PatientSpawn` (у уличного входа) → пациент идёт через лобби со
стульями → входит в Reception через западную дверь → очередь у стойки
(`Reception.InteractionZone`) → после решения уходит через восточную дверь
в коридор и дальше в нужный кабинет.

## Дерево в Workspace

```
Workspace
  Hospital                  Model, атрибут LayoutVersion = 2
    Corridor                Model
      Structure             Folder: Floor, Ceiling, Wall x N, Lintel x N
      EntryPoint            Part
    Rooms                   Folder

        Structure           Folder: Floor, Ceiling, Wall, Lintel,

      HeartMonitor          Model (то же)
      Surgery               Model (то же)
      BreakRoom             Model (то же)
```

## Атрибуты моделей комнат

- `RoomId` - строковый идентификатор, совпадает с именем модели (`BasicMedical`, `XRay`, ...).
- `DisplayName` - человекочитаемое название.
- `RoomNumber` - номер по роадмапу, только у четырёх кабинетов (1, 2, 7, 8).

Этап 1 (`RoomRegistry`) будет опираться на `RoomId`, так что менять имена моделей
без правки реестра нельзя. Lobby в реестр не входит — это не кабинет с механикой,
а зал ожидания.

## Маркерные части

- `EntryPoint` - 4 x 0.4 x 4, зелёный, `CanCollide = false`. Точка, куда ставится
  пациент при входе в комнату. У кабинетов стоит в 4 студах от двери внутри комнаты
  автоматически (когда дверь одна); у Lobby и Reception задана явно, так как у
  них по две двери и "просто за дверью" неоднозначно.
- `InteractionZone` - 12 x 8 x 12 у большинства комнат, у Reception 8 x 20
  перед стойкой, у Lobby 18 x 22 (всё лобби). Полупрозрачный, `CanCollide = false`,
  `CanTouch` и `CanQuery` оставлены включёнными, чтобы этап 1 мог ловить вход через
  `Touched` или `GetPartsInPart`.
- `RoomLabel` - табличка на стене, заданной полем `signSide`; текст в
  `RoomLabel.Display.Text`. У Lobby висит над уличным входом (снаружи),
  у остальных комнат — со стороны коридора.

## Lobby (вход и зал ожидания)

22 x 26, между уличным входом (запад, X = -64) и Reception (восток, X = -42).
Шесть стульев двумя рядами у северной и южной стен (`ChairSeat` + `ChairBack`,
по три в ряд, X = -60 / -53 / -46), оставляют свободным центральный проход
по Z от -9 до 9 между входом и дверью в Reception.

- `PatientSpawn` в точке (-61, 0, 0), сразу за уличной дверью.

## Reception

32 x 26, вдвое больше исходной версии. Стойка стоит по X = -30 и делит комнату
надвое: очередь пациентов из Lobby с запада (X от -42 до -30), игрок с востока
(X от -30 до -10), выход в коридор через восточную дверь. Стойка перекрывает
Z от -9 до 9, по краям остаются проходы по 3.5-4 студа, чтобы впущенный пациент
мог обойти её и уйти в коридор.

- `PlayerSpawn` (SpawnLocation) в точке (-18, 0.5, 0).
